# OptiPic - Premium Image Compression Tool

A fully responsive, SEO-optimized, and premium-designed image compression tool built with HTML, CSS, and JavaScript.

## Features

- **Dynamic Compression**: Adjust quality levels in real-time.
- **Format Conversion**: Convert images to JPEG, PNG, or WEBP.
- **Image Resizing**: Set custom max width and height dimensions.
- **Modern Design**: Glassmorphism UI with smooth animations.
- **Privacy Focused**: All processing happens in the browser (Client-side); no images are uploaded to a server.
- **Responsive**: Works perfectly on desktop, tablet, and mobile.
- **Monetization Ready**: Integrated Google AdSense placeholders.

## Setup Instructions

1. **Hosting**: Simply upload the files (`index.html`, `style.css`, `script.js`) to any web server or static hosting provider (e.g., GitHub Pages, Netlify, Vercel).
2. **AdSense Integration**:
   - Open `index.html`.
   - Search for `YOUR_AD_CLIENT_ID` and replace it with your Google AdSense Publisher ID (e.g., `ca-pub-XXXXXXXXXXXXXXXX`).
   - Search for `YOUR_AD_SLOT_ID` and replace it with your specific Ad Unit IDs for the top and bottom ad spaces.

## Customization

- **Colors**: Edit the `:root` variables in `style.css` to change the color scheme.
- **Fonts**: The project uses 'Outfit' from Google Fonts. You can change this in the `<head>` of `index.html` and the CSS variables.

## Browser Support

Supports all modern browsers (Chrome, Firefox, Safari, Edge) with HTML5 Canvas and WebP support.
